# COMPONENT INVENTORY

- **Navbar / Header**: Used across all Public/Auth/Borrower/Owner screens.
- **Footer**: Used across all non-admin screens.
- **AdminSidebar**: Used in all `/admin/*` screens.
- **ProductCard / Bento Box**: Found in Explore, Categories, Home, Dashboards.
- **StatusBadge**: Indicates rental status (e.g. Active, Pending) found in Dashboards and Details.
- **AvailabilityCalendar**: Found in Product Details and Owner Calendar.
- **DataTable**: Used extensively in Admin screens (Users, Products, Finance).
- **PriceBreakdown (Escrow)**: Found in Checkout Review.
- **EmptyState**: Explicitly designed in `code (9).html` and `code (31).html`.
- **Notification Dropdown**: Represented in `code (18).html`.
