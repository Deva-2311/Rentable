# Rental Marketplace (MERN) — Enterprise Architecture

> **Project Goal:** Build a scalable rental marketplace (similar to Airbnb) for renting physical products such as bikes, cameras, gaming consoles, electronics, furniture, tools, and more.

---

# Technology Stack (MERN)

## Frontend

* React.js (Vite) *(or Next.js if SSR/SEO is required)*
* React Router
* Tailwind CSS
* Shadcn/UI
* Framer Motion
* React Hook Form
* Zod Validation
* Axios
* React Query (TanStack Query)
* Redux Toolkit (Authentication + Global State)
* React Hot Toast

---

## Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* Bcrypt
* Cloudinary
* Multer
* Razorpay
* Nodemailer
* Socket.io (notifications)
* Redis (optional for caching & OTP)

---

## Database

MongoDB Atlas

# Scalability Roadmap

**Phase 1 (MVP)**

* Authentication
* Product listings
* Search & filters
* Booking requests
* Razorpay payments
* Reviews
* Owner & borrower dashboards
* Admin panel

**Phase 2**

* Real-time chat (Socket.io)
* Push notifications
* Wishlist
* Coupons & promotions
* Dynamic pricing
* Wallet refunds
* Multi-image optimization

**Phase 3**

* AI-powered product recommendations
* Identity verification (KYC)
* Geo-location search with maps
* Rental insurance integration
* Multi-vendor support
* Mobile apps (React Native)

This architecture follows modern MERN best practices with a feature-driven structure, normalized MongoDB collections, RBAC, secure JWT authentication, scalable API design, and a clean separation of concerns. It is suitable for an MVP and can grow into a production-grade rental marketplace serving thousands of users.

3. **Project Mega Master Prompt** (defines the entire architecture and coding standards)

These are written as if you're hiring a senior software architect.

## Suggested development order

To get the highest-quality AI-generated code, work through the project in this sequence rather than asking for everything at once:

1. Project setup (frontend + backend)
2. Authentication & RBAC
3. Database models
4. Landing page & shared UI
5. Product management
6. Search & filtering
7. Booking system
8. Razorpay payment integration
9. Borrower dashboard
10. Owner dashboard
11. Admin panel
12. Notifications & email
13. Reviews & ratings
14. Performance optimization, testing, and deployment

This incremental approach produces cleaner, more maintainable code than trying to generate the entire application in a single prompt.
